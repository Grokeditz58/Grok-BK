# Kyp Durron

Evidence file for Kyp Durron, **Star Wars Legends** continuity. Each entry is a short description of what he does or what is said about him, followed by the full quote in a code block with its source. Anti-feats and limitations are in their own section at the end, each backed by quotes.

**How to read this file**

- Quotes are copied word for word from the sources, with whitespace and curly quotes normalized. `[…]` marks an omission inside a quote.

- The source line is the last line inside each code block, so one copy gets the quote and its citation. Novels are cited with the chapter where we could find it.

- **†** after a source means the quote was transcribed from a published source that was not re-checked against our own copy of the text (film dialogue, DVD commentary, guides, comics). Everything else was matched against the text on file.
