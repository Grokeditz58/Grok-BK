# Star Wars Notes

Star Wars Legends power-scaling research notes: per-character feat/quote files, debate write-ups,
source-material notes (books, comics, guides, game guides), verdicts and feat lists.

## Start here

- [Character index](characters/INDEX.md) — one file per character (very large characters are split into a folder of parts with its own README)
- [Notes index](notes/INDEX.md) — source materials (books, comics, guides), debates, daily research
- [Verdicts](verdicts.md) — matchup verdicts (opinion, not feats)
- [Legends feats](legends-feats.md) — verified Legends feats and quotes
- [Canon feats](canon-feats.md)

## Folders

| Folder | What's in it |
|---|---|
| `characters/` | Per-character feat/quote files, `INDEX.md`, `README.md` (format rules); `pdf/` has PDF exports; big characters are folders (e.g. `characters/darth-vader/`) |
| `notes/` | `INDEX.md`, `materials/` (book/comic/guide notes + panel images + PDFs), `debates/` (PDFs), `daily-research/` |
| `suspect-insight/` | Suspect Insight forum debate notes (`debates/`, `debate-index.md`) and respect threads (`respect-threads/`, see `DIRECTORY.md`) |
| `primary/` | Reading-order inventory, a Legends timeline snapshot and game notes |
| `external/mega-notes/` | Reference library of quotes, respect threads, novel notes and debate notes from another researcher; `CATALOG.md` describes it |

## How to search

- **Website:** open the repo and press `/` (or click the search bar), type your term; GitHub limits it to this repo when you search from inside it. Use quotes for exact phrases. Press `t` on the Code tab to jump to a file by name.
- **GitHub phone app:** open the repo → **Code** → tap the search icon (or use the main Search tab and filter to Code in this repo).
- Inside a long file on the web, use your browser's find (Ctrl/Cmd+F) or the file's symbol/outline button to jump between `##` sections.

Note: GitHub code search only indexes files under ~384 KB, so for very large files search will find the filename but may not match text deep inside them; open the file (or its split parts) and use find-in-page.

Note: entry counts printed in some index/header lines were computed before a public-release cleanup and may be slightly higher than the entries now present. Many internal cross-references point to working files that are not part of this repository.
