## Notes and exclusions
- This is an official licensed DK/Lucasfilm title from 2005, so it counts as Legends. No fan-made pages were found.
- The main scan (MOswnJTb) is missing pp. 68–69 (Rogues and Villains). Those pages were read from the alternate MEGA scan EHskzZ7I, a library copy where file number = page + 4. That copy has 152 files; its last ones (index, acknowledgments, blank, Geonosis endpapers, back flap, back cover) add nothing beyond the main scan.
- Scan-group tags in filenames, e.g. "(bZc-DCP)", are not book content.
- In-book inconsistencies and printing errors are flagged in the chunk files (see summary.md).
- This is a reference book with no sequential panels, so no daily-image crops were made. Only these notes and PDFs are committed; no scans or page images are stored.
