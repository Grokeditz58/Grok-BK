# 049: Star Wars: Obsession #1–5 (Dark Horse, Nov 2004 – Apr 2005)

Status: DONE (2026-11-03). Full hand-read, one page at a time, of all five issues: covers, credits/crawl pages and every story page (#1 24 files, #2 24, #3 24, #4 22 files including two double-page spreads, #5 24; 118 files in total). Tiny lettering was checked with zoomed crops.

Credits: script Haden Blackman; art Brian Ching; colors Sno Cone Studios; lettering Michael David Thomas; covers Brian Ching and Brad Anderson; designer Debra Bailey; associate editor Jeremy Barlow; editor Randy Stradley; publisher Mike Richardson. Every issue's credits page says: "The events in this story take place approximately five months before the events in Revenge of the Sith." Official Dark Horse/Lucasfilm comic (Legends continuity, Clone Wars era).

## Citation convention
`Ob#N pNN` = scan file index within issue N, where p1 (fc) is the cover and p2 the credits/crawl page. In #4, files 006 and 013 are double-page spreads, so later file numbers run lower than the printed page numbers.
