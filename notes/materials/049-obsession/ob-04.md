# Star Wars: Obsession #4 (Dark Horse, March 2005): hand-read notes

Credits: script Haden Blackman; art Brian Ching; colors Sno Cone Studios; letters Michael David Thomas; cover Brian Ching and Brad Anderson; editor Randy Stradley. Timeline (p2): "approximately five months before the events in Revenge of the Sith." MEGA handle 5f9CnTjZ.

Citation convention: "Ob#4 pNN" is the scan file index within the issue, where p1 (fc) is the cover and p2 the credits/crawl page. In #4, files 006 and 013 are double-page spreads, so the 22 files carry 24 printed pages; citations use the file index. [KEY] marks a strong page; "crop candidate" marks art considered for daily-image-candidates.md. Speaker attributions follow balloon tails; uncertain ones are flagged.
