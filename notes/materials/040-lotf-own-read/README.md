# Owner Material 040 — Legacy of the Force, own full read (Betrayal, Revelation, Invincible)

- **Source:** licensed Del Rey ebook editions of *Legacy of the Force* 1 *Betrayal* (Aaron Allston, 2006), 8 *Revelation* (Karen Traviss, 2008) and 9 *Invincible* (Troy Denning, 2008), from the owner's MEGA folder. Legends, 40–41 ABY.
- **Method:** every chapter read in full, in order; chapter notes were written every 2–3 chapters, then compiled into one file per book. No keyword scanning.
- **Citation:** [cNN ¶L] = chapter NN, paragraph L of that chapter's text (chapter heading = ¶1); [prl]/[epl] = prologue/epilogue. Every double-quoted passage was checked against the text with a script (exact match).
- **Per book:** summary; feats table; statements table; blow-by-blow fight log with conditions; character analyses; scaling chains; honest takeaway; differences vs the older reference notes in `021-legacy-of-the-force/` (which was not modified).
- **No novel text is stored here**: only short quotes inside notes. Source files are deleted after reading.
