## Notes and exclusions
- All five are official licensed DK/Lucasfilm titles. The latest, from 2012, is still before April 2014, so all count as Legends. No fan-made pages were found.
- Scan watermarks (e.g. "starboris.galeon.com" on VD1) and scan-group filename tags are not book content and were ignored.
- The main expanded Ep I scan (NCs0RBrI) stops at p. 97. The alternate MEGA copy (Ifk01brC) is complete, so the last pages were read from it.
- These are reference books with no narrative, so no daily-image crops were made. Only these notes and PDFs are committed; no scans or page images are stored.
