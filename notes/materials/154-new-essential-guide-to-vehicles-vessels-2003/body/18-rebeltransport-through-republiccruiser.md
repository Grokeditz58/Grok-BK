# NEGVV 2003 — notes154: Rebel Transport → Republic Cruiser (printed 112–117 / scan 134–139)

## Printed 112–113 / S134–135 — Rebel Transport (*Bright Hope*) (Gallofree Yards Medium Transport / GR-75)
- **Readout:** **90 m**; **900 G / Class 4 / 650 kph**; Gallofree Yards, Inc.; Rebel Alliance.
- Hoth “Rebel transport”; *Bright Hope* last off Hoth. Discount common among Alliance. **19,000** metric tons cargo; durasteel plate shell over modular pods held by magnetic + rudimentary deflector. Variants: troop/medical/armory/fuel. Prone to malfunction; slow; rarely armed (typically 4 retractable twin lasers) → need X-wing/ion escort. Command pod easy target → destroy = helpless.
- **Quote (C-3PO to Leia, Hoth):** “Your Highness, we must take the last transport! It’s our only hope!”
- **Schematics:** 1 Deflector shield gen; 2 Armored hull; 3 Command pod; 4 Primary drive engines; 5 Main reactor; 6 Landing gear.

## Printed 114–115 / S136–137 — Republic Assault Ship (RHE Acclamator-class Transgalactic Military Assault Ship)
- **Readout:** **752 m**; **3,500 G / Class 0.6**; Rothana Heavy Engineering (KDY sub); Old Republic.
- Clone army transport: **16,000** clones, **320** bikes, **48** AT-TE, **80** gunships, **36** SPA. Arms: 12 TL / 24 lasers / proton tubes. Redundant shields; can kill smaller ships though not primary ship-to-ship. Precursor to Imperial Star Destroyers → later obsolete.
- **Quote (Lama Su):** “Master Sifo-Dyas requested the most powerful army in the galaxy. We have worked with only the best shipbuilders to fulfill that request.”
- **Schematics:** 1 Primary thruster; 2 Main bridge; 3 Missile launch tubes; 4 Hyperdrive generator; 5 Armored access hatch for clone troops.

## Printed 116–117 / S138–139 — Republic Cruiser (*Radiant VII*) (CEC Consular-class Space Cruiser)
- **Readout:** **115 m**; **2,040 G / Class 2 / 900 kph**; Corellian Engineering Corporation; Old Republic.
- For dignitaries/diplomats/Jedi; cost-cut utilitarian vs prior extravagance. Scarlet diplomatic paint. Modular salon pod (alien environments / armored; later cargo/docking). Originally unarmed (shields); Clone Wars → double TL + concussion. Diplomatic crew: 2 comm / 3 eng / 2 pilots / captain / utility droids. *Radiant VII* Naboo mission: skeleton 1 pilot + captain — both killed when TF destroyed cruiser.
- **Quote (Jull Dremon, TF gunner):** “Don't they know that painting the ship red only makes it a better target?”
- **Schematics:** 1 Sensor dish; 2 Comm array; 3 Sublight engine; 4 Deflector shield gen; 5 Salon pod; 6 Main forward sensors; 7 Cockpit.
