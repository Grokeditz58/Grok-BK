# 042: Star Wars: Darth Vader and the Lost Command #1–5 (Dark Horse, Jan–May 2011) + TPB (Nov 2011)

Status: DONE (2026-11-03). This is a full hand-read, one page at a time, of all five issues: covers, crawl and indicia pages, and every story page. The TPB front and back matter were also read. This was the first read of this series, which had never been covered before.

Credits: script Haden Blackman; pencils Rick Leonardi; inks Daniel Green; colors Wes Dzioba; lettering Michael Heisler; issue covers Tsuneo Sanda; TPB front cover Michael Kutsche; editor Randy Stradley. Setting: c. 19 BBY (Rise of the Empire era).

## Citation convention
`LC#N p. NN` = the scan file index within issue N, with 01 = cover and 02 = crawl/credits page. In LC#3, file 04 is a double-page spread, so file numbers after it run one lower than printed pages. TPB citations use the TPB file index (000–119).
