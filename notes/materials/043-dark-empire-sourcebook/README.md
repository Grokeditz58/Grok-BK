# Owner Material 043 — Dark Empire Sourcebook (West End Games, 1993), hand-read

- **Source:** *Dark Empire Sourcebook* by Michael Allen Horne (WEG Star Wars RPG, D6, 1993), a 135-page PDF scan from the owner's MEGA folder. Only official licensed Legends material was used.
- **Method:** every page was read in order (cover, credits, intro, Ch. 1–9, back cover). Nothing was keyword-screened. Quotes are verbatim from the text layer. Pages that are only art are noted in each chunk.
- **Citation:** "— p. N" is the **printed** page number (PDF page − 1).
- **Labels:** Feat / Statement / stat bullets, plus (ANALYSIS), which marks my reasoning, not the book.
- **Files:**
  - `01-front-and-new-republic-a.md` (pp. 1–17)
  - `02-new-republic-b-and-empire-reborn-a.md` (pp. 18–39; Emperor stats)
  - `03-empire-reborn-b-and-fringe.md` (pp. 39–60; Boba Fett, Pestage, Mako Spince)
  - `04-the-force.md` (pp. 61–81; Holocron, Vima-Da-Boda, Adepts, new dark side powers)
  - `05-planets-and-starships-a.md` (pp. 81–100; Byss, Coruscant, Eclipse, Sovereign)
  - `06-starships-b-and-world-devastators.md` (pp. 100–119)
  - `07-vehicles-and-equipment.md` (pp. 120–133; Universal Energy Cage, cloning, planetary shields)
  - `summary.md`
