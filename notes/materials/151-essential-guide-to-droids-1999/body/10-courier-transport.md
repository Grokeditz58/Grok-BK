# COURIER / TRANSPORT — P90–93 (S057–058)

## Messenger Droid / Message Drone — P90–91 (S057)
- **Arakyd Seeker AS-M12:** Fast nearly-foolproof dispatcher; small metal sphere on repulsors (scaled-down probot); tools tucked (sensors, computer input jack, retractable manipulator). Delivers via holo projector or vocabulator after verbal passcode. Lore: Luke + Dash Rendar encountered one at Obi-Wan’s Tatooine hut.
- **IA Elegance Message Drone:** 9 m long relics; some govs + remote Imperial outposts; ~24,000 credits complete system. Almost all engine; one hyperspace jump then refuel; broadcasts beacon on arrival; fail-safe self-destruct (electrite crystal) incinerates ≤600 m vs tampering. Lore: Wedge + Luke retrieved one from Death Star debris post-Endor → alerted Alliance to Ssi-ruuk Bakura invasion.
**Schematics:** AS-M12 Front — Computer Interface Jack retracted, Auditory Sensors, Photoreceptor-Holographic Projector, Repulsorlift Engine Housing, Manipulator Arm retracted, Vocabulator (+ human torso/head scale). Elegance Side — Beacon Transmitter, Self-Destruct Mechanism, Message Storage Banks, Hyperdrive Engine and Motivator, Sensor Package (+ human vs 9 m length).

## Drone Barge — P92–93 (S058)
Voluminous cargo tankers piloted by simple droid brains (cost-effective predictable routes); low-value/hazardous cargo (grain, ice, industrial waste). Mfrs: Gallofree Yards (pre-bankruptcy) + CEC **StarHauler** line. No life-support/crew quarters. Shipjackers (e.g. Tanith Shire) exploit simple programming → drop from hyperspace for plunder.
**Schematics:** StarHauler 131-T3 Side — Primary Drive Engine, Repulsorlift Coils, External Storage Tanks (fluids), Reactor Core, Forward Scanner Array, Interior Cargo Hold (metals), Beacon Sensor. StarHauler 131-SX2 Side — Primary Drive Engine, Solar Sensors, Beacon Sensor, External Storage Tanks (ore/scrap), Repulsorlift Engine, Forward Scanner Array. Scale: X-wing silhouette each.
